Portfolio folder

Showing the built-in demo portfolio.

Link the local folder named “<Studio> Portfolio” (e.g. Storm Portfolio). The app detects the studio from the folder name and reads everything from disk — nothing is uploaded. You only do this once.

This browser can't open a local folder. Please use Google Chrome or Microsoft Edge on a computer.

How to organise your portfolio folder

Link one folder per studio, named <Studio> Portfolio. Inside it, make one folder per deliverable type. Files are named by brand:

Storm Portfolio/             ← link once · name = "<Studio> Portfolio"
├── Logos/                   ← Apex Builders-Logotype.png  (png · jpg · pdf)
├── Brand Guidelines/        ← Apex Builders-Brand Guidelines.pdf
├── Social Media Kit/        ← Apex Builders.png
├── Stationery/              ← Apex Builders.pdf
└── Logo Animation/          ← Apex Builders.mp4 / .gif

File formats accepted

LogosPNG / JPG render in the deck · PDF/SVG are listed & downloadable
Brand Guidelines · StationeryPDF (preview & download) · images also fine
Social Media KitPNG / JPG images
Logo AnimationGIF / MP4 / WEBM

Naming

  • Folder name = <Studio> Portfolio — the studio identity is detected from it.
  • Logo files: Brand Name-Logotype.png. Guidelines: Brand Name-Brand Guidelines.pdf.
  • Everything else: just the Brand Name + extension. The brand is read from the file name.
