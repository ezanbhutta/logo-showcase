Logo library folder

Using the built-in demo logos.

Connect the local folder where your logo library lives — usually your Google Drive for Desktop folder. It's read on your computer; nothing is uploaded. You only do this once.

This browser can't open a local folder. Please use Google Chrome or Microsoft Edge on a computer.

How to organise your library folder

Point the app at one library folder. Inside it, create one sub-folder per studio. Each studio folder holds a logos/ folder plus a tags.csv (and an optional theme.json):

Logo Library/            ← the folder you attach
├── storm/               ← one folder per studio (kebab-case)
│   ├── logos/           ← master images live here
│   │   ├── apex-builders.png
│   │   └── greenleaf.png
│   ├── tags.csv         ← the label sheet (required)
│   └── theme.json       ← colours & fonts (optional)
├── eikon/
│   └── …
└── grid/ …

File formats required

logos/*.pngPNG · transparent background preferred · ≥ 1200 px on the long edge
tags.csvCSV · UTF-8, comma-separated, with a header row
theme.jsonJSON · optional · the studio's palette, fonts, layout

Naming rules

  • Studio folder — short, lowercase, hyphens not spaces: abdul-haseeb, grid.
  • Logo file — lowercase, hyphens, unique, and it must match the file column in tags.csv.
  • No spaces, capitals or symbols in any file or folder name.

What goes in tags.csv

One row per logo. Columns: file, name, industries, types, tier, year, active, notes.

fileFilename in logos/ (the join key).
nameBrand name shown on the tile.
industriesOne or more, separated by |. From the list below.
typesOne or more, separated by |. From the list below.
tier1–5. 1 = flagship (shown first), 5 = filler.
year · active · notesOptional. active=false hides a logo.

How to categorise

Values must come from these lists (the app rejects anything else, so labels never drift).
